# graphify-out : carte du projet

La carte (graphe de connaissances) des deux dépôts réunis, le portfolio et Cyber, faite avec l'outil Graphify. Elle n'est pas publiée sur le site.

| Fichier | Contenu |
|---|---|
| [`GRAPH_REPORT.md`](GRAPH_REPORT.md) | Le résumé à lire en premier : éléments centraux, groupes de thèmes, liens surprenants. |
| [`graph.html`](graph.html) | La carte interactive, à ouvrir dans un navigateur. |
| [`graph.json`](graph.json) | Le graphe complet, lisible par l'outil `graphify`. |

La carte est une photo du projet au 11/11/2026 : elle peut être en retard sur les fichiers. Elle se régénère après un gros changement.
